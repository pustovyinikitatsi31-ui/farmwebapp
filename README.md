## Технічна реалізація

### HTML

- Семантична розмітка: `header`, `nav`, `main`, `section`, `article`, `footer`.
- Спільні header і footer на всіх сторінках; поточна сторінка в меню позначена `aria-current="page"`.
- Кожне поле форм має `label`, пов'язаний з полем через `for`/`id`.
- Зображення мають `alt`, `width`, `height` та `loading="lazy"`.

### CSS (`css/style.css`)

- **Змінні в `:root`:** `--green`, `--green-dark`, `--green-soft`, `--text`, `--white`, `--radius`.
- **Типографіка:** шрифт Tinos (Google Fonts), основний текст 1.125rem, міжрядковий інтервал 1.65, довжина рядка абзаців до 70ch.
- **Flexbox:** шапка та навігація.
- **CSS Grid:** сітка карток `.grid` та блок `.intro` на сторінці товару.
- **Адаптивність (mobile-first):**

| Екран | Брейкпоінт | Сітка карток |
|---|---|---|
| Мобільний | до 599 px | 1 колонка |
| Планшет | від 600 px | 2 колонки |
| Десктоп | від 992 px | 3 колонки, шапка в один рядок |

- **Доступність:** `:focus-visible`, `prefers-reduced-motion`.

### Валідація форм (HTML5)

| Атрибут | Де використано |
|---|---|
| `required` | усі обов'язкові поля |
| `type="email"` | поле Email |
| `type="tel"` + `pattern="[0-9]{10,13}"` | телефон |
| `minlength` | ім'я (2), адреса (10), пароль (6) |
| `min` / `max` | кількість товару (1–100), дата не раніше сьогодні |
| `maxlength` | коментар (300 символів) |

Форми працюють без сервера: після успішної валідації показується підтвердження.

## Запуск

1. Клонувати репозиторій:
   ```bash
   git clone https://github.com/pustovyinikitatsi31-ui/farmwebapp.git
   ```
2. Відкрити `index.html` у браузері. Сервер і встановлення залежностей не потрібні.

## Перевірка

- Валідність HTML: [validator.w3.org](https://validator.w3.org/) — усі 6 сторінок без помилок і попереджень. Під час перевірки знайдено й виправлено: `index.html` (1 помилка: `h3` після `h1` без `h2`, і 1 попередження: `section` без заголовка) та `catalog.html` (1 попередження: `section` без заголовка, замінено на `div`).
- Валідність CSS: [jigsaw.w3.org/css-validator](https://jigsaw.w3.org/css-validator/) — `css/style.css` без помилок (CSS3 + SVG).
- Браузер: Google Chrome 157.0.8103.38
- Перевірені ширини екрана: 375 px, 768 px, 1200 px
