# Green Farm — ЛР №3 (тестування)

Це третя лабораторна по нашому магазину фермерської продукції «Green Farm».
Тут ми тестували сервер (Node.js + Express + SQLite): писали тест-план, тести і баг-репорти.

Зробили: Пустовий Н., Бурлаков Г., Познанський А. (ЦІ-31)

## Як запустити

Треба Node.js 22.13 або новіший.

```
npm install
npm start
```

Сайт буде на http://localhost:3000

## Як запустити тести

```
npm run test:unit       # unit-тести (сервер запускати не треба)
npm run test:api        # API-тести (сервер має бути запущений, тому спочатку npm start)
npm run test:coverage   # unit-тести + покриття коду
npm run test:report     # усе разом, результат у test-report.txt
```

## Що є в проєкті

- `server.js` — сам сервер
- `unit.test.js` — 6 unit-тестів
- `api.test.js` — 9 API-тестів
- `unit-log.txt`, `api-log.txt`, `test-report.txt` — логи, які тести пишуть самі
- звіт — `Звіт_ЛР3_Тестування_GreenFarm.docx`

## Що протестували

- unit-тести: 6 з 6 пройшли
- API-тести: 9 з 9 пройшли
- ручні тести: 5 штук, 4 пройшли, 1 впав (MT-05)
- покриття server.js: функції 100%, гілки 80%, рядки 56,80%

Рядків мало, бо тест не бачить обробники маршрутів Express. Їх перевіряють API-тести.
